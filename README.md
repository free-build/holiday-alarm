# 智能节假日闹钟 v6.6

基于用户提供的 Cherri 源码实现。运行时只读取 iPhone 苹果日历里的“中国大陆节假日”日历，不访问其他节假日数据源，也不上传诊断日志。源码位于 `src/智能节假日闹钟_v6.6.cherri`，用户原稿保存在 `reference/用户提供的_v4.cherri`。

## 直接下载

无需自行编译，可下载已签名的 [智能节假日闹钟 v6.6](build/智能节假日闹钟_v6.6.shortcut) 并在 iPhone 上导入。请先在日历 App 中启用并同步“中国大陆节假日”日历。

## 配置

直接修改源码开头的 `@alarmConfig`，每行闹钟使用 `HH:mm|名称`。受管闹钟统一使用 `节假日-` 前缀并每天重复。再次运行时按名称复用已有闹钟；同名重复闹钟只保留一个；删除配置行后，对应的受管闹钟会被删除，其他闹钟不受影响。

当天日历事件名称含“班”则开启闹钟，含“休”则关闭闹钟；两者都没有时按普通工作日和周末判断。“班”的优先级高于“休”。快捷指令只判断当天，不判断次日，也不识别具体节日名称。

睡眠闹钟联动默认关闭。健康 App 已设置睡眠定时的用户可将 `睡眠闹钟|关` 改为 `睡眠闹钟|开`。启用后，周一至周五按“班/休”处理下一次睡眠闹钟；自然周六、周日不调用睡眠闹钟操作，避免系统已按重复计划跳过时弹出错误。

测试日期直接写在同一配置文本中：`260925` 或 `260925|测试日期` 表示模拟 2026 年 9 月 25 日，`|测试日期` 表示使用真实今天。测试行不会创建闹钟。

`调试日志|开` 会把本次判断日志复制到剪贴板并显示；`调试日志|关` 则不复制、不显示。两种模式都不会把日志发送到网络。

## 构建

运行 `./build.sh --check`，输出未签名的快捷指令和可检查的 plist。需要 Cherri v2.3.0，或通过 `CHERRI_BIN` 指定编译器。`tools/fix_calendar_filter.py` 写入苹果日历筛选条件与原生 Clock 动作元数据；`tools/check_plist.py` 校验日历条件、闹钟动作、测试日期和无联网动作等约束。

`./build.sh --sign` 会通过第三方 HubSign 服务生成可直接导入 iPhone 的 `build/智能节假日闹钟_v6.6.shortcut`。未签名文件不能直接导入 iPhone。

## 验证

Cherri v2.3.0 在 Linux ARM64 上编译通过，最终产物包含 362 个动作且联网动作数量为 0。iPhone 实测已覆盖普通周末、工作日、2026-06-19“端午节（休）”和 2026-10-10“国庆节（班）”。
